# Quality of Life

## Alternate Current

[Alternate Current](https://modrinth.com/mod/alternate-current) significantly improves the performance of redstone.

In testing, redstone creations which consistently crashed the server before now don't affect performance.

## Amendments

[Amendments](https://modrinth.com/mod/amendments) changes various vanilla blocks to make them behave nicer.

## AppleSkin

The [AppleSkin](https://modrinth.com/mod/appleskin) mod improves the HUD in various ways, including:

- Adding visual indicators for saturation and exhaustion.
- Adding visual indicators for potential hunger/starvation/health recovery while holding food.

## Bridging

The [Bridging Mod](https://modrinth.com/mod/bridging-mod) provides "Reach-Around Placement" for blocks, similar to Bedrock Edition and the Quark mod.

There is a keybinding for toggling bridging, which is by default bound to the comma (`,`) key.

When bridging will happen, the mod adds arrows around the crosshair to indicate where the block will be placed.
If you don't fully understand what the crosshairs mean or how bridging works,
the [documentation on modrinth](https://modrinth.com/mod/bridging-mod) explains it pretty well.

## Comforts

The [Comforts](https://modrinth.com/mod/comforts) mod adds sleeping backs and hammocks.

## Cosmetic Armor

The [Cosmetic Armor Reworked](https://www.curseforge.com/minecraft/mc-mods/cosmetic-armor-reworked)
mod adds "cosmetic armor" slots in your inventory.

These cosmetic armor slots let you have your normal set of armor for defense and effects, and a cosmetic set which is purely visual.

Cosmetic armor is retained after death.*

(* After the next server update, because it required a configuration change.)

## Easy Elyta Takeoff

[Easy Elytra Takeoff](https://modrinth.com/mod/easy-elytra-takeoff) allows easier takeoff with an elytra, by holding fireworks in your main hand
and right-clicking in the air.

Without this mod, you have to jump and carefully time the right click, which is difficult if there's any lag.

## Equal Sapling Rates

By default, some trees drop very few saplings. [Equal Sapling Rates](https://modrinth.com/datapack/equalsaplingrates) makes it easier to re-plant trees after cutting them down. 

## Move Boats &amp; Move Minecarts

The [Move Boats](https://modrinth.com/mod/move-boats) mod lets you:

- **pick up a boat** by crouching and right-clicking the boat with an empty hand
- **release a boat** by standing up and crouching once

The [Move Minecarts](https://modrinth.com/mod/move-minecarts) mod adds the same behaviors for minecarts.

## Passive Shield

Your shield is hidden unless you're using it. It also provides some passive protection, but less than actively using the shield.

This is added by the [Passive Shield](https://modrinth.com/mod/passive-shield) mod.

## Sit Anywhere

You can [Sit Anywhere](https://modrinth.com/datapack/sit-anywhere!) by either:

- looking directly down, crouching twice, and right clicking; or
- running the `/trigger sit` command

Additionally, if you're on a slab or stairs, you can just stand on it and right click it.

## TreeChop

[HT's TreeChop](https://modrinth.com/mod/treechop) allows you to chop trees by repeatedly breaking a single block.


In the TreeChop settings (default binding: `n`), you can turn off this functionality.

Crouching while chopping a tree inverts whether TreeChop is enabled:
- if you have it off, crouching while chopping will use TreeChop
- if you have it on, crouching while chopping will use normal block breaking
