# Client Modpack Updates

We handle as much as we can via via [Automodpack](https://modrinth.com/mod/automodpack).

However, some client-only mods and changing Neoforge versions can't be updated that way.

## Build 33 — Neoforge update &amp; more Quality-of-Life mods

This is the first big client update we've had.

The notable changes we've made are:

- Update to Neoforge 21.1.228
- Updated all mods to their latest versions
- Added 4 client-only mods:
  - [better f3](https://modrinth.com/mod/betterf3)
  - [fusion connected textures](https://modrinth.com/mod/fusion-connected-textures)
  - [light level overlay](https://modrinth.com/mod/llo)
  - [extreme sound muffler](https://modrinth.com/mod/extreme_sound_muffler)

If you don't have the modpack installed yet, you can just [follow the Getting Started section of the Introduction](/).

Otherwise, this should update you to the latest version:

1. [Drag this link to the main Prism Launcher window](https://github.com/canine-systems/advanced-colonies/releases/latest/download/advanced-colonies.mrpack).
2. Click "OK"
3. Click "Update existing instance"

That's it. You're done. Please ping duckinator on Discord and let them know you've updated!
