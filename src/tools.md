# Useful Tools

- An **[Explorer's Compass](https://modrinth.com/mod/explorers-compass)** allows you to locate structures anywhere in the world.
- A **[Nature's Compass](https://modrinth.com/mod/natures-compass)** allows you to search for biomes anywhere in the world.
- **Silk Touch** now extends to more items via [Silkier Touch](https://modrinth.com/mod/silkier-touch).
- [Simply Tools](https://modrinth.com/mod/simply-tools) makes two notable additions:
  - A **Hammer** is equivalent to a pickaxe, but mines a 3x3 area.
  - An **Excavator** is equivalent to a shovel, but digs a 3x3 area.
