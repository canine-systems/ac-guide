# Storage

Our modpack provides the following storage-related mods:

- [Ender Storage](#ender-storage)
- [Sophisticated Backpacks](#sophisticated-backpacks)
- [Sophisticated Storage](#sophisticated-storage)

## Ender Storage

[Ender Storage](https://modrinth.com/mod/ender-storage) adds new chests that link together based on matching color patterns.

All EnderChests with the same color buttons share the same inventory.

EnderPouches access the EnderChest inventory with matching colors. The colors of an EnderPouch can be set by using it on an EnderChest.

There are also EnderTanks work similarly to EnderChests, but for liquids.

## Sophisticated Backpacks

[Sophisticated Backpacks](https://modrinth.com/mod/sophisticated-backpacks) adds upgradable and customizable backpacks.

[Sophisticated Backpacks Create Integration](https://modrinth.com/mod/sophisticated-backpacks-create-integration) lets you use Backpacks from Sophisticated Backpacks on Create contraptions.

[Create: Sophisticated Backpacks Compat](https://modrinth.com/mod/create-sophisticated-backpacks-compat) lets you use Create machines to make _Sophisticated Backpacks_ items.

The starter kit includes one.

Sometimes mobs spawn with them.

## Sophisticated Storage

[Sophisticated Storage](https://modrinth.com/mod/sophisticated-storage) aadds Barrels, Chests, and Shulker Boxes for storage.

All of them can be upgraded and personalized.

[Sophisticated Storage Create Integration](https://modrinth.com/mod/sophisticated-storage-create-integration) lets you use _Sophisticated Storage_ blocks on Create contraptions.
