# Ars Nouveau

This chapter discusses [Ars Nouveau](https://modrinth.com/mod/ars-nouveau).

The following mods provide tighter integration between Ars Nouveau and other mods:

* **Ars Creo:** integration with Create
* **Ars Nouveau's Flavors &amp; Delight:** integration with Farmer's Delight
* **Ars Polymorphia:** integration with Polymorph
* **Ars Énergistique:** integration with Applied Energistics 2
* **Reliquified Ars Nouveau:** integration with Relics

We additionally have the **Ars Elemental** mod, which adds glyphs and spell foci.
