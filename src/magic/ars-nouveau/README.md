# Ars Nouveau

This chapter discusses [Ars Nouveau](https://modrinth.com/mod/ars-nouveau).

The following mods provide tighter integration between Ars Nouveau and other mods:

* **[Ars Creo](https://www.curseforge.com/minecraft/mc-mods/ars-creo):** integration with Create
* **[Ars Nouveau's Flavors &amp; Delight](https://modrinth.com/mod/arsdelight):** integration with Farmer's Delight
* **[Ars Polymorphia](https://modrinth.com/mod/ars-polymorphia):** integration with Polymorph
* **[Ars Énergistique](https://modrinth.com/mod/ars-energistique):** integration with Applied Energistics 2

We additionally have the following add-on mods for Ars Nouveau:

* **[Ars Elemental](https://www.curseforge.com/minecraft/mc-mods/ars-elemental)**: adds glyphs and spell foci.
* **[Ars Zero](https://www.curseforge.com/minecraft/mc-mods/ars-zero):** adds cast devices and glyphs.
